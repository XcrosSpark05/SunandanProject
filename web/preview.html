🎥 How to Add This Overlay in OBS Studio:

  1. In OBS Studio, click the + (Add Source) button under Sources.
  2. Select Browser and name it "Cricket Scoreboard".
  3. Paste your live Vercel URL (e.g. https://your-app.vercel.app/?room=cricket-live-1).
  4. Set Width to 1920 and Height to 1080.
  5. Check "Shutdown source when not visible".
  6. Click OK. The transparent ticker strip will appear at the bottom of your live video stream!
